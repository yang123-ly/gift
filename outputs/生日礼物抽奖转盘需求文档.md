# 生日礼物抽奖转盘 — 需求文档

## 一、项目概述

一个以「生日礼物」为主题的抽奖转盘应用，包含**抽奖页**和**转盘管理页**两个页面。所有礼物初始为未知状态，用户需通过上传图片/拍照获取抽奖券进行抽奖，抽中后礼物才会揭晓真实图片，且每个礼物只能被抽中一次。

---

## 二、功能需求

### 1. 抽奖转盘页（礼物抽奖）

#### 1.1 转盘展示
- 转盘按奖品数量均分扇形，扇形填充奖品颜色，外圈装饰交替彩色灯珠（旋转时闪烁）
- 顶部金色指针，中央圆形「抽奖」按钮
- **神秘礼物机制**：
  - 未抽中的扇形显示紫色渐变底 +「?」+「神秘礼物」文字，**不展示真实图片和名称**
  - 只有被抽中过的礼物，才在转盘上展示真实图片（圆形裁剪）和名称
- 转盘下方展示：抽奖券余额、剩余礼物数量、「获取抽奖券」按钮

#### 1.2 抽奖规则
- 每次抽奖消耗 **1 张抽奖券**，券不足时点击抽奖自动弹出获取抽奖券引导
- 抽奖只从**剩余未揭晓**的礼物中按权重（概率）随机抽取，**每个礼物只能被抽中一次**
- 中奖结果先按权重计算，再反推转盘停止角度，保证指针精确停在中奖扇形中心
- 转盘旋转 5 秒以上（至少 5 圈，ease-out 缓动），旋转期间禁用按钮
- 所有礼物抽完后：按钮变为「已抽完」，提供「重置礼物」按钮（需二次确认），重置后全部恢复未知状态

#### 1.3 中奖反馈
- 旋转结束弹出中奖弹窗：礼物真实图片（圆形大图）、名称、稀有度徽章，标题为「神秘礼物揭晓」
- 同时按礼物配置的特效类型触发**全屏特效**（约 3.5 秒）：
  | 特效 | 说明 |
  |------|------|
  | 彩带雨 | 彩色纸片从顶部飘落旋转 |
  | 烟花绽放 | 多枚烟花升空爆炸，放射状粒子带重力拖尾 |
  | 金币雨 | 金色金币旋转下落 |
  | 星光爆裂 | 屏幕中心向四周爆裂星形闪光粒子 |
  | 无特效 | 不播放特效 |

#### 1.4 侧边栏
- **礼物墙**：展示所有礼物，已揭晓的显示图片+名称+稀有度，未揭晓的显示「神秘礼物 ?」；顶部显示揭晓进度（已揭晓 x/总数）
- **抽奖记录**：本次会话内最多保留 10 条，含礼物图片、名称、时间

### 2. 抽奖券系统

- 新用户初始赠送 **3 张**抽奖券，余额持久化保存
- 获取方式：**上传图片** 或 **拍照**（调用设备摄像头）
- 获取流程：选择/拍摄图片 → 预览 → 提交校验（约 1.8 秒动画）→ 获得 1 张抽奖券
- 成功后可「继续获取」或「去抽奖」

### 3. 转盘管理页

- **统计卡片**：奖品总数、总概率、传说奖品数、最高概率奖品
- **概率分布图**：横向条形图展示各奖品概率占比；总概率 ≠ 100% 时显示黄色警告（说明按权重归一化）
- **奖品表格**：图片缩略图、名称、颜色、稀有度徽章、概率（支持 +/- 微调或直接编辑）、中奖特效、操作（编辑/删除，删除需确认）
- **新增/编辑奖品弹窗**，可配置：
  - 奖品名称（必填）
  - 奖品图片：8 张预设网络图片可选，或粘贴自定义图片链接，带实时预览
  - 图标：12 个 FontAwesome 图标候选
  - 颜色：8 个预设色块 + 自定义取色器
  - 中奖概率：0-100，滑块 + 数字输入
  - 稀有度：普通 / 稀有 / 史诗 / 传说（不同颜色徽章）
  - 中奖特效：彩带雨 / 烟花绽放 / 金币雨 / 星光爆裂 / 无特效
- **恢复默认**按钮：一键还原默认奖品配置（需确认）
- 所有配置自动保存到浏览器本地，刷新不丢失

## 三、视觉设计要求

- **生日温馨主题**：
  - 页面背景使用网络生日氛围图（气球、蛋糕），叠加暖粉紫色调滤镜
  - 应用标题「生日礼物抽奖」，Logo 为生日蛋糕图标
  - 转盘外圈粉金渐变描边，底盘奶油粉色，周围粉色柔光呼吸光晕
  - 转盘上方标语：「生日快乐 · 幸运礼物抽奖」「每一份礼物，都是满满的心意」
- 深色主题 + 金色/粉色点缀，卡片半透明毛玻璃质感
- 丰富的悬停状态、过渡动画和微交互（按钮缩放、光晕脉动、弹窗弹入动画等）
- 图标统一使用 FontAwesome，图片资源使用 Unsplash 网络图

## 五、数据说明

### 奖品数据结构
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| name | string | 奖品名称 |
| icon | string | FontAwesome 图标 |
| image | string | 奖品图片链接 |
| color | string | 扇形颜色 |
| probability | number | 中奖权重（0-100） |
| effect | enum | 中奖特效类型 |
| rarity | enum | 稀有度（common/rare/epic/legendary） |

### 默认奖品（8 个）
玫瑰鲜花、惊喜礼盒、香水礼盒、蓝牙耳机、金币大奖、奢华彩妆、钻石之心、谢谢参与

### 持久化存储（localStorage）
- 奖品配置
- 抽奖券余额
- 已揭晓礼物 ID 列表
